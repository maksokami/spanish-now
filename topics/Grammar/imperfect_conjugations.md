# Imperfect Tense Conjugations

The imperfect tense is used to describe ongoing, habitual, or repeated actions in the past, as well as background information (like time or weather). For regular verbs, **-er** and **-ir** verbs share the exact same endings.

## Regular -AR Verbs (e.g., *Hablar* - to speak)

| Pronoun | Ending | Example (*Hablar*) | Translation |
|---------|--------|-------------------|-------------|
| Yo | -aba | habl**aba** | I used to speak / was speaking |
| Tú | -abas | habl**abas** | You used to speak / were speaking |
| Él, Ella, Usted | -aba | habl**aba** | He/She/You used to speak / was speaking |
| Nosotros/as | -ábamos | habl**ábamos** | We used to speak / were speaking |
| Vosotros/as | -abais | habl**abais** | You all used to speak / were speaking |
| Ellos, Ellas, Ustedes | -aban | habl**aban** | They/You all used to speak / were speaking |

## Regular -ER Verbs (e.g., *Comer* - to eat)

| Pronoun | Ending | Example (*Comer*) | Translation |
|---------|--------|-------------------|-------------|
| Yo | -ía | com**ía** | I used to eat / was eating |
| Tú | -ías | com**ías** | You used to eat / were eating |
| Él, Ella, Usted | -ía | com**ía** | He/She/You used to eat / was eating |
| Nosotros/as | -íamos | com**íamos** | We used to eat / were eating |
| Vosotros/as | -íais | com**íais** | You all used to eat / were eating |
| Ellos, Ellas, Ustedes | -ían | com**ían** | They/You all used to eat / were eating |
